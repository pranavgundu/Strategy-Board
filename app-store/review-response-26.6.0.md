It begins with a fresh launch and demonstrates the typical user flow: creating a match, entering the six alliance team numbers, drawing plans for autonomous, transition, active, inactive/endgame, and notes, viewing match statistics, and returning to the saved match list. It also demonstrates the optional The Blue Alliance import and sharing/export controls.

1. Purpose and target audience

Strategy Board is a digital strategy whiteboard for FIRST Robotics Competition teams. Its target audience is student team members, drive teams, coaches, and mentors who plan match strategy before and during robotics competitions. It replaces paper field diagrams and scattered notes with a single field-based board. Users can assign the six alliance teams, draw color-coded robot paths and annotations for each phase of a match, keep notes, review optional match insights, and share a selected plan with teammates.

2. Setup and access

No account, registration, subscription, payment, organization membership, or login is required. No sample file is required.

To access the main features:

- Launch the app in landscape orientation.
- If prompted, enter an optional team number; this preference can be skipped or changed later.
- Tap New, enter a match name and the red and blue alliance team numbers, then save.
- Open the match and use Auto, Transition, Active, Inactive/Endgame, Notes, and Stats to build and review the plan.
- Drawing tools are available directly on the field. Matches and preferences are saved locally on the device.
- TBA optionally imports public event schedules and team assignments from The Blue Alliance. An individual API key is not required for review.
- Import QR uses the camera only after the user chooses that feature and grants permission. Import Link accepts a temporary Strategy Board share code or URL.
- Share uploads only the selected match board and returns a temporary six-character link intended to expire after seven days. QR export can transfer a plan without an account.

3. External services, tools, and platforms

- The Blue Alliance API: optional public FIRST Robotics Competition event, team, and match data import.
- Statbotics API: optional public statistical match and team insights.
- Google Firebase Firestore: optional, user-initiated temporary storage of a selected shared match board. The app does not use Firebase Authentication.
- GitHub: public project/contributor information and support links.
- Apple operating-system services: local app storage, HTTPS networking, share/export interfaces, and optional camera access for QR scanning.

The app does not use payment processors, in-app purchases, subscriptions, advertising networks, analytics SDKs, AI services, or third-party authentication.

4. Regional availability

The app functions consistently in every region where it is available. There are no region-specific features, content, accounts, prices, or restrictions. Availability of optional third-party data imports depends only on network access to those public services.
